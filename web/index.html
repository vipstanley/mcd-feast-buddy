麦麦饭局

一句话发起聚餐，AI 拉真实菜单 + 领真实券 + 用官方接口报出真实价格，再按「谁吃什么」AA 分账。
本版只做到店自取，默认停在下单前——你说「下单」它才会创建订单。

它解决什么

聚餐痛点麦麦饭局怎么做
七嘴八舌点不齐一句话收集人数、预算、忌口
套餐贵还是单点贵算不清价格只来自官方 calculate-price，不做心算
有人忌口没人管查套餐详情，只换掉冲突的那一轮子项
AA 分账扯皮按「谁点了什么」分摊，合计严格等于实付
下单要来回切 App说「下单」才创建订单并返回支付链接

安装

  1. 打开 open.mcd.cn/mcp，手机号登录 → 控制台 → 激活，领取 MCP Token
  2. WorkBuddy 左侧【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】
  3. 填入 mcp-config.example.json 中的配置，把 ${MCD_MCP_TOKEN} 换成你的 Token，保存并启用
  4. 加载本 Skill，直接对话即可
