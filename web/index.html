麦麦饭局

一句话发起聚餐，AI 凑出最划算且合忌口的一单，AA 分账，直出支付链接。

它解决什么

聚餐痛点麦麦饭局怎么做
七嘴八舌点不齐一句话收集人数、预算、忌口
套餐贵还是单点贵算不清单点/套餐/优惠券统一比价，说出省了多少
有人忌口没人管用营养数据过滤，并精准替换套餐内单品
AA 分账扯皮按「谁点了什么」自动算每人应付
下单要来回切 App确认后直接创建订单，返回支付链接

安装

  1. 打开 open.mcd.cn/mcp，手机号登录 → 控制台 → 激活，领取 MCP Token
  2. WorkBuddy 左侧【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】
  3. 填入 mcp-config.example.json 中的配置，把 ${MCD_MCP_TOKEN} 换成你的 Token，保存并启用
  4. 加载本 Skill，直接对话即可
