# 麦麦饭局 McFeast

把「一群人点麦当劳」这件扯皮的事，压缩成一句话。

## 前置条件

- 已在 WorkBuddy 连接器启用 `mcd-mcp`（麦当劳官方 MCP，Streamable HTTP）
- 未配置时：提示用户前往 <https://open.mcd.cn/mcp> 手机号登录 → 控制台 → 激活，领取 MCP Token

## 何时使用

用户表达以下任一意图时启用：多人聚餐点单、团餐/下午茶、人均预算凑单、忌口搭配、AA 分账。

## 工作流程

### 第 0 步 · 收集需求（自然语言，不要像表单一样逼问）

- **必填**：人数、就餐方式（外送到家 / 到店取餐）、地址或门店
- **选填**：人均预算、忌口（不吃辣 / 不要牛肉 / 素食 / 控热量）、口味偏好

信息不全时**最多追问一轮**，之后用合理默认值继续推进（默认：就近门店、不设预算上限、无特殊忌口）。

### 第 1 步 · 确认餐段与门店

- `now-time-info` — 判断当前餐段（早餐 / 正餐 / 下午茶），餐段决定可售菜单
- 到店取餐 → `query-nearby-stores`
- 外送 → `delivery-query-stores`；若用户无收货地址，先 `delivery-query-addresses`，必要时 `delivery-create-address`

### 第 2 步 · 拉取菜单

- `query-meals` — 当前门店可售菜单（分类、餐品编码、标签）
- 对候选套餐调用 `query-meal-detail` — 拿套餐组成与**可替换项**

### 第 3 步 · 忌口与约束过滤

- `list-nutrition-foods` — 按营养成分过滤
- 约束类型：不吃辣、不要牛肉、素食、控热量上限
- **关键原则：优先"替换"而非"放弃"**。用 `query-meal-detail` 的可替换项换掉冲突单品，保住套餐优惠，而不是为了一个人弃掉整单

### 第 4 步 · 汇总优惠券

- `auto-bind-coupons` — 一键领取麦麦省当前可领券
- `available-coupons`、`query-my-coupons`、`query-store-coupons` — 汇总账户与门店下全部可用券

### 第 5 步 · 统一比价

- 构造候选池：**A 全单点 / B 全套餐 / C 套餐+单点混搭**，各方案再叠加可用券
- 对每个候选调用 `calculate-price`
- 选出实付最低且满足忌口约束的方案

### 第 6 步 · AA 分账（本地计算）

按「谁点了什么」分摊：

1. 可明确归属的单品 → 归属人承担
2. 共享项（如大份薯条、多人套餐）→ 按人数均分
3. 优惠券减免 → 按各自商品金额**比例**分摊，而非简单均分
4. 配送费 → 按人数均分
5. 保留 2 位小数，**分账尾差调整到最后一个人**，保证各人应付之和恰好等于实付总额

### 第 7 步 · 下单（必须显式确认）

> ⚠️ **默认停在这一步之前**，只呈现方案与支付预估，绝不自动下单。

只有用户明确说「下单 / 确认 / 就要这个」时才继续：
- `create-order` — 创建订单，返回支付链接
- `query-order` — 追踪订单状态与进度

## 输出格式

```
🍔 麦麦饭局方案（N 人 / 门店：XXX）

✅ 推荐组合  原价 ¥XXX → 实付 ¥XXX（省 ¥XX，X.X 折）
   用了：{券名}

📋 明细
   · {品名} ×N   ¥XX → ¥XX（{替换/优惠说明}）
   ⚠️ 已按忌口排除：{被排除项}

💰 AA 分账
   {分组/姓名}   ¥XX.XX

🔗 回复「确认」创建订单并生成支付链接
```

## 硬性约束（安全红线）

1. **绝不未经用户显式确认调用 `create-order`** —— 这是真实交易
2. 价格一律以 `calculate-price` 返回为准，**禁止自行心算或估算**
3. 券不可用、门店售罄、触发 429 限流时**如实告知**，不伪造结果、不编造价格
4. MCP Token 仅由连接器读取，**不在对话中打印或回显**
5. 输出仅供参考，餐品价格与供应状态以麦当劳官方实时结果为准

## 错误码处理

| 现象 | 处理 |
|---|---|
| `401` | Token 无效或过期 → 提示重新申请并更新连接器配置 |
| `429` | 触发 600 次/分钟限流 → 降低调用频率，复用已拉取的菜单与券数据 |
| 门店售罄 / 品项不可售 | 给出同价位替代品并说明差异 |
| 无可用券 | 明确说明"当前无可用券"，不要假装省了钱 |
