# 麦麦饭局 McFeast

> 一句话发起聚餐，AI 拉真实菜单 + 领真实券 + 用官方接口报出真实价格，再按「谁吃什么」AA 分账。
>
> 本版只做**到店自取**，默认**停在下单前**——你说「下单」它才会创建订单。
>
> 仓库：<https://github.com/vipstanley/mcd-feast-buddy>

基于麦当劳官方 MCP（`M-China/mcd-mcp-server`）构建的 WorkBuddy Skill，专治「部门下午茶 / 宿舍团餐 / 朋友聚会点麦当劳」时那个永恒难题：
**谁想吃什么说不清、套餐和单点哪个划算算不明、最后谁付多少分不清。**

---

## 它解决什么

| 聚餐痛点 | McFeast 怎么做 |
| --- | --- |
| 七嘴八舌点不齐 | 一句话收集：人数、城市与地标、人均预算、忌口（不吃辣 / 不要牛肉 / 素食） |
| 套餐贵还是单点贵算不清 | 价格只来自官方 `calculate-price`，不做心算；明确说出原价、实付、省了多少 |
| 有人忌口没人管 | 查套餐详情换掉冲突的那一轮子项，而不是为一个人放弃整单 |
| AA 分账扯皮 | 按谁点了什么分摊，尾差加到最后一人，合计严格等于实付 |
| 下单要来回切 App | 认可方案后说「下单」，才创建订单并返回支付链接 |

---

## 目标用户

- 经常组织团队下午茶 / 项目庆功的职场人
- 宿舍、社团、实验室成群下单的学生
- 想让朋友聚餐点单不再扯皮的任何人

## 安装方法

### 前置：申请麦当劳 MCP Token

1. 打开 <https://open.mcd.cn/mcp>，点击右上角【登录】，手机号验证登录
2. 右上角变为【控制台】后点开，点击【激活】申请 MCP Token
3. 同意服务协议，复制生成的 Token

### 在 WorkBuddy 中接入

1. 打开 WorkBuddy → 左侧【专家·技能·连接器】→【连接器】
2. 右上角【自定义连接器】→【配置 MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer <你的 MCP Token>"
      }
    }
  }
}
```

3. 替换 `<你的 MCP Token>` 后保存，回到列表将 `mcd-mcp` 【启用】，首次启用点【信任】
4. 连通性自测：对话中输入一句聚餐需求（如「2 个人在上海市人民广场附近吃点什么」），能返回真实门店与菜单即代表 MCP 已通

> 安全提示：真实配置只保存在本地 `mcp-config.json`（已被 `.gitignore` 忽略），仓库中仅提供 `mcp-config.example.json` 占位符版本。

### 安装本 Skill

```bash
git clone https://github.com/vipstanley/mcd-feast-buddy.git
```

将仓库中的 `skill/` 目录放入 WorkBuddy 的 Skill 目录，或在 WorkBuddy 中直接加载该 Skill 后即可对话使用。

想先看效果，直接打开 `web/index.html` 即可（单页介绍与输出示例，无需 Token）。

## 使用示例

**输入（一句话）**

> 4 个人到店聚餐，上海市 人民广场 附近，1 个人不吃辣，人均 30 以内，帮我们凑一单最划算的并 AA 分账。

**输出（真实运行，2026-10-25 12:57 于麦当劳上海黄浦华旭国际大厦餐厅）**

```
🍔 麦麦饭局方案（4 人 · 麦当劳上海黄浦华旭国际大厦餐厅）

✅ 实付 ¥117.20（原价 ¥140.30，省 ¥23.10）
   用券：麦辣鸡腿堡三件套券 → 挂在「麦辣鸡腿堡3件套」这一行（¥46.00 → ¥22.90）
   已为你一键领取 3 张麦麦省券（11.9元麦辣鸡腿堡 / 19.9元王牌炸鸡任选2 / 免费脆薯饼）

📋 明细（来自 calculate-price）
   · 麦麦周末双人餐 ×1        ¥50.90  第 1、2 位共享（第 2 轮已换板烧鸡腿堡）
   · 龙焰鸡腿堡三件套 ×1      ¥26.90  第 4 位
   · 蓝莓爆爆珠麦旋风 ×1      ¥16.50  全员共享
   · 麦辣鸡腿堡3件套 ×1       ¥22.90（原 ¥46.00）第 3 位，用券
   ⚠️ 已按忌口处理：第 1 位不吃辣，双人餐第 2 轮由麦辣鸡腿汉堡换成板烧鸡腿堡（+¥1）

💰 AA 分账
   第 1 位   ¥29.57
   第 2 位   ¥29.57
   第 3 位   ¥27.02
   第 4 位   ¥31.04
   （合计 ¥117.20 = 实付）

🔗 价格以支付页为准。回复「下单」我才会创建订单；回复「换店 / 换菜 / 不要券」可调整
```

上面每一个数字都来自 `calculate-price` 的返回字段，没有一个是算出来的。完整入参与逐行返回见下方记录。
