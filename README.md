# 麦麦饭局 McFeast

> 一句话发起聚餐，AI 自动凑出**最划算 + 合口味**的一单，AA 分账，直出支付链接。

基于麦当劳官方 MCP（`M-China/mcd-mcp-server`）构建的 WorkBuddy Skill，专治「部门下午茶 / 宿舍团餐 / 朋友聚会点麦当劳」时那个永恒难题：
**谁想吃什么说不清、套餐和单点哪个划算算不明、最后谁付多少分不清。**

---

## 它解决什么

| 聚餐痛点 | McFeast 怎么做 |
| --- | --- |
| 七嘴八舌点不齐 | 一句话收集：人数、人均预算、忌口（不吃辣 / 不要牛肉 / 素食）、口味偏好 |
| 套餐贵还是单点贵算不清 | 把「单点 / 套餐 / 优惠券」放进同一个候选池统一比价，说出省了多少 |
| 有人忌口没人管 | 用营养与餐品数据做过滤，忌口项直接排除 |
| AA 分账扯皮 | 按谁点了什么自动算出每人应付，生成分账清单 |
| 下单要来回切 App | 确认后直接创建订单，返回支付链接与订单进度 |

---

## 目标用户

- 经常组织团队下午茶 / 项目庆功的职场人
- 宿舍、社团、实验室成群下单的学生
- 想让朋友聚餐点单不再扯皮的任何人

## 安装方法

### 前置：申请麦当劳 MCP Token

1. 打开 <https://open.mcd.cn/mcp>，点击右上角【登录】，手机号验证登录
2. 右上角变为【控制台】后点开，点击【激活】申请 MCP Token
3. 同意服务协议，复制生成的 Token

### 在 WorkBuddy 中接入

1. 打开 WorkBuddy → 左侧【专家·技能·连接器】→【连接器】
2. 右上角【自定义连接器】→【配置 MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer <你的 MCP Token>"
      }
    }
  }
}
```

3. 替换 `<你的 MCP Token>` 后保存，回到列表将 `mcd-mcp` 【启用】，首次启用点【信任】
4. 连通性自测：对话中输入「现在几点」，能返回当前时间即代表 MCP 已通

> 安全提示：真实配置只保存在本地 `mcp-config.json`（已被 `.gitignore` 忽略），仓库中仅提供 `mcp-config.example.json` 占位符版本。

### 安装本 Skill

将本仓库 `skill/` 目录放入 WorkBuddy 的 Skill 目录，或在 WorkBuddy 中直接加载本 Skill 后即可对话使用。
